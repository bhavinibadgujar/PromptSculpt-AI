# PromptSculpt AI

Shape Better Prompts. Unlock Better AI.

## Overview
PromptSculpt AI is an AI-powered prompt evaluation platform that analyzes prompt quality, identifies weaknesses, and generates improved prompts using a transparent evaluation framework.

## Features
- Prompt Quality Score
- AI Prompt Analysis
- Weakness Detection
- Prompt Improvement
- Before vs After Comparison
- Prompt History

## Tech Stack
- React
- Tailwind CSS
- FastAPI
- SQLite
- OpenAI API
